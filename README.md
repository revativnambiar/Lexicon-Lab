# LEXICON LAB
### The Interactive English Learning & Communication Platform
**Tagline:** *Learn. Explore. Express.*

---

## 1. Project Overview

**LEXICON LAB** is a complete, premium, fully functional educational platform designed to elevate students' English language competency through active, practical learning. Moving beyond static textbook memorization, the platform provides interactive studios for grammar mechanics, vocabulary expansion, critical reading comprehension, heuristic-assisted writing composition, and custom speech preparation.

The website is engineered with a professional EdTech startup aesthetic featuring clean typography, rounded cards with subtle elevation shadows, smooth micro-interactions, responsive design across mobile/tablet/desktop, and a consistent palette:
- **Primary:** Deep Navy Blue (`#102A43`)
- **Secondary:** Clean White (`#FFFFFF`)
- **Accent:** Soft Light Blue (`#DCEAF7`)
- **Interactive Blue:** Slate Blue (`#1E6091`)
- **Background:** Very Light Grey (`#F7F9FC`)
- **Text:** Dark Navy and Charcoal (`#0B1B2B`, `#334E68`, `#627D98`)

## 3. Platform Modules & Features

### A. Home Page
- **Hero Section**: "Unlock the Power of English." with supporting pedagogical explanation, prominent "Start Learning" call-to-action, and an interactive educational SVG canvas.
- **Course Outcome Alignment Banner**: Prominent pill row with quick access to the institutional academic mapping modal.
- **Five Specialized Learning Studios**: Interactive overview cards with feature lists and direct navigation links.
- **Why Choose Lexicon Lab**: 6 pedagogical cards emphasizing active practice over passive notes, authentic writing heuristics, any-topic speech synthesis, genuine local storage, and zero fabricated metrics.
- **Feature Highlights**: Real, non-fabricated platform statistics (7 Grammar Modules, 15 Sentence Correction Challenges, 5 Deep Reading Passages, Infinite Any-Topic Speeches).

### B. Grammar Studio (CO1)
- **7 Comprehensive Lessons**:
  1. *Tenses & Aspect* (Past, Present, Future with Simple, Continuous, Perfect, Perfect Continuous formulas)
  2. *Parts of Speech* (Nouns, Pronouns, Verbs, Adjectives, Adverbs, Prepositions, Conjunctions, Interjections)
  3. *Articles & Determiners* (A vs. An by phonetic sound, Definite "The", and Zero Article rules)
  4. *Prepositions in Context* (Time: at/on/in, Place: at/on/in/between/among, Dependent prepositions)
  5. *Subject-Verb Agreement* (Singular/plural, intervening phrases, indefinite pronouns, correlative conjunctions)
  6. *Sentence Formation & Structure* (Simple, Compound, Complex, Compound-Complex; avoiding comma splices and run-ons)
  7. *Active and Passive Voice* (Tense conversion rules, agent omission, objective scientific reporting)
- **Interactive Grammar Quizzes**: Multi-question quizzes with instant green/red answer highlighting, rule explanations, score calculation, retake options, and progress persistence.
- **Interactive Sentence Correction Studio**:
  - Displays flawed student sentences (e.g., *"She go to college every morning."*).
  - Student types the corrected sentence.
  - Checks capitalization, whitespace, and grammatical accuracy against accepted variations.
  - Side-by-side comparison highlighting errors with grammatical explanation.

### C. Word Explorer (CO1)
- **Word of the Day**: Prominently highlights featured words (e.g., *"Eloquent"*), phonetic spelling, audio pronunciation button (`window.speechSynthesis`), part of speech, definition, synonyms, antonyms, contextual sentences, memory hook, and Latin/Greek etymology.
- **Shuffle Word**: Allows students to rotate and explore random vocabulary words.
- **Dictionary Search & Filters**: Live search input across words, meanings, and synonyms with difficulty filters (*Foundational*, *Intermediate*, *Advanced*).
- **Idioms & Phrases Collection**: Curated collection of English idioms (e.g., *"Bite the bullet"*, *"Burn the midnight oil"*, *"Break the ice"*) with figurative meanings, historical origins, and practical sentences.
- **Vocabulary Quiz**: Challenge assessing synonyms, antonyms, definitions, and idiomatic expressions with instant score tracking.

### D. Reading Hub (CO4)
- **Passage Collection**: 5 original, thought-provoking reading texts:
  1. *Technology*: "The AI Frontier: Balancing Algorithmic Power and Human Agency" (382 words)
  2. *Science*: "Neuroplasticity: Rewiring the Adult Brain for Lifelong Learning" (412 words)
  3. *Environment*: "The Circular Economy: Reimagining Resource Stewardship" (395 words)
  4. *Society*: "The Evolving Nature of Human Communication in a Hyper-Connected World" (420 words)
  5. *Personal Development*: "The Architecture of Deep Focus: Reclaiming Attention in a Distracted Age" (405 words)
- **Reader Interface**: Book-style typography, reading time estimates, word counts, and font scaling controls (`A-`, `A`, `A+`).
- **Comprehension Questions**: Factual and inferential multiple-choice questions with immediate explanations.
- **Dedicated Summary Writing Activity**:
  - Textarea for typing concise summaries.
  - Live word counter and target range monitor (50–80 words).
  - Automated rubric evaluation: conciseness score, key themes captured checklist, and originality check.
  - Side-by-side comparison of the student's submission against an accredited Model Summary.

### E. Writing Studio (CO1)
- **5 Writing Practice Categories**:
  1. *Essay Writing* (Argumentative, Expository, Analytical)
  2. *Paragraph Writing* (Unity, Coherence, Descriptive)
  3. *Letter Writing* (Formal applications, complaints, and informal correspondence)
  4. *Report Writing* (Executive summary, findings, and recommendations)
  5. *Creative Writing* (Imagery, pacing, sensory storytelling)
- **Prompt & Template Management**: Curated prompts + custom topic input, format tips, and an "Insert Format Template" button injecting structured outlines.
- **Real-Time Writing Assistant**:
  - Genuine rule-based spelling suggestions (100+ common misspellings with 1-click correction).
  - Grammar pattern alerts (subject-verb agreement, double modals, article misuse, confused homophones).
  - Sentence length alerts (>35 words) and terminal punctuation reminders.
  - Live Flesch Reading Ease score and grade level calculation.
- **Draft Management**: Save drafts to `localStorage`, view draft history, download as `.txt`, and copy to clipboard.

### F. Speech Corner (CO5)
- **Any-Topic Input**: Type ANY topic into the input field or pick from trending prompts (*Artificial Intelligence*, *Climate Change*, *Importance of Education*, *Women Empowerment*, etc.).
- **Speech Customization**:
  - Duration: 1 min (~130 words), 2 mins (~260 words), 3 mins (~400 words), 5 mins (~650 words).
  - Language Level: Beginner, Intermediate, Advanced.
  - Speech Style: Informative, Persuasive, Motivational.
- **Rhetorical Synthesis Engine**: Synthesizes a three-part speech:
  - *Introduction*: Rhetorical hook (question/quote), contextual framing, and thesis preview.
  - *Main Body*: 2 to 4 structured paragraphs with transition words, practical illustrations, and logical progression.
  - *Conclusion*: Synthesizing summary and an inspiring Call to Action.
- **Delivery Annotations**: In-line pause cues (`[Pause for emphasis]`, `[Eye contact across the room]`, `[Vocal energy rise]`) toggleable with a single checkbox.
- **Web Speech Audio Playback Rehearsal**: Listen to the speech delivered aloud with play, pause, stop, and speed adjustment (0.8x, 1.0x, 1.2x).
- **Speech Delivery Guidance**: Expert tips on posture, eye contact, pause mastery, and stage fright management, plus a comprehensive guide on "How to Begin, Organize, and Conclude Confidently."
- **Speech History**: Revisit previously prepared speeches anytime from local storage.

### G. Student Dashboard
- **Welcome Banner**: Displays student name (editable), date, overall completion percentage, and master progress bar.
- **8 Metric Summary Cards**: Grammar lessons reviewed, quiz accuracy average, sentence corrections solved, vocabulary words bookmarked, passages read, summaries evaluated, words written, and speeches prepared.
- **Course Outcomes Milestone Tracks**: Dedicated progress bars and status indicators for CO1, CO4, and CO5.
- **Activity Log Timeline**: Real-time chronological timeline tracking completed quizzes, submitted summaries, saved drafts, and generated speeches.
- **Progress Reset**: Clean reset button for evaluations and fresh test cycles.

## 4. How to Run & Explore

### Option 1: Direct File Launch (No dependencies needed)
Simply double-click or open `index.html` in any modern web browser (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari). All features, audio speech synthesis, dictionary search, quizzes, and local storage work immediately out of the box!

```bash
# Windows Explorer or PowerShell
start index.html
```

### Option 2: Local Static Server (Node.js)
A lightweight zero-dependency static server is included:

```bash
# Start server
node server.js
# Or
npm start
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
